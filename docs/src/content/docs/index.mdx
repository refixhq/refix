:::caution
ReFIX is in early development. Building messages and the session layer are not implemented yet, and APIs change
between 0.x releases.
:::

## What works today

- Read FIX logs as they are, with any separator and a logger's prefix before each message.
- Read fields as typed values through generated FIX 4.4 messages.
- Generate typed messages from your own dictionary.

## Install

<Tabs syncKey="language">
	<TabItem label="Python">
		```sh
		pip install refix refix-fix44
		```

		Requires Python 3.12 or later.
	</TabItem>
	<TabItem label="Rust">
		```sh
		cargo add refix refix-fix44
		```

		Requires Rust 1.88 or later.
	</TabItem>
</Tabs>

`refix` reads messages, and `refix-fix44` adds the typed FIX 4.4 messages.
