Read a FIX log and print each order's fields as typed values.

## Install

<Tabs syncKey="language">
	<TabItem label="Python">

		pip install refix refix-fix44
		```
	</TabItem>
	<TabItem label="Rust">

		cargo add refix refix-fix44
		```

## A log to read

Save this as `fix.log`. It holds a NewOrderSingle and a Heartbeat, each after a logger's prefix.

```text title="fix.log"
2026-10-08 09:30:00.000 OUT 8=FIX.4.4|9=118|35=D|49=SENDER|56=TARGET|34=1|52=20261008-09:30:00|11=ORDER-1|55=ACME|54=1|60=20261008-09:30:00|40=2|44=101.25|38=100|10=194|
2026-10-08 09:30:00.250 IN  8=FIX.4.4|9=5|35=0|10=163|
```

## Read the orders

<Tabs syncKey="language">
	<TabItem label="Python">
		```python
		import refix
		from refix_fix44 import CODEC, NewOrderSingle

		for record in refix.decode_log("fix.log", CODEC):
		    order = record.message
		    if isinstance(order, NewOrderSingle):
		        print(order.cl_ord_id, order.instrument.symbol, order.side.name, order.price)
		```

		```text
		ORDER-1 ACME BUY 101.25
		```

		A field that is absent reads as `None`, and a value that cannot be read raises `InvalidValueError`.
	</TabItem>
	<TabItem label="Rust">
		```rust
		use refix::message::LogReader;
		use refix_fix44::{DIALECT, Message};

		fn main() -> Result<(), Box<dyn std::error::Error>> {
		    let mut reader = LogReader::new(DIALECT, None);
		    reader.feed(&std::fs::read("fix.log")?);
		    for record in reader.finish() {
		        let Message::NewOrderSingle(order) = Message::from_raw(record.message) else {
		            continue;
		        };
		        let (Some(id), Some(symbol), Some(side), Some(price)) = (
		            order.cl_ord_id()?,
		            order.instrument().symbol()?,
		            order.side()?,
		            order.price()?,
		        ) else {
		            continue;
		        };
		        println!("{id} {symbol} {side:?} {price}");
		    }
		    Ok(())
		}
		```

		```text
		ORDER-1 ACME Buy 101.25
		```

		A field that is absent reads as `Ok(None)`, and a value that cannot be read is an `Err`.
	</TabItem>
</Tabs>

The reader finds each message after its prefix and works out the separator the log uses. Each message is then read
as the type its MsgType names, so the Heartbeat is skipped here.

FIX 4.4 keeps Symbol (55) in its Instrument component, so the order reads it through `instrument`.
[Typed messages](/guides/typed-messages/#components) covers components, groups and the header.
